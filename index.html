Outside work I build with ESP32s, run my own home servers and teach kids how electronics and code fit together.

Bollard test rig

A rig to prove our bollards before they go in the ground. I designed the structural frame for static load testing of marine bollards, checked the member sizes with FEA and prepared the fabrication and assembly drawings.

On top of that sits an automated duty-cycle tester. An ESP32 runs the test sequence and a live web dashboard, an STM32 reads the sensors, and a relay module drives the bollard controller. It counts every up and down cycle, watches position, motor current, supply voltage and core temperature, and logs it all to flash.

  • FEA
  • Fabrication drawings
  • ESP32
  • STM32
  • Relay control
  • Web dashboard

Universal car dashboard

A modular instrument cluster that can go into almost any light vehicle and still meet Australian standards. We wrote it in C++ on a Raspberry Pi 5, with gauges, navigation prompts and warning lights on one screen.

Before locking in the design we ran a public survey to find the cluster layout drivers found easiest to read, then built the final version around the results.
