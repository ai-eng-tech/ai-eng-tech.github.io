# Portfolio of Sifat Salehin Ananyo

Electrical engineer in design, projects and commissioning. Live at https://ai-eng-tech.github.io

Plain HTML, CSS and JavaScript, no build step.

- `index.html` has all the content. Edit text there.
- `style.css` has the look.
- `main.js` runs the scroll trace, the boom gate intro, galleries and the lightbox.
- `assets/img/` holds the project pictures (WebP, max 1400 px).

To add a project, copy one `<article class="sheet">` block in `index.html`, change the text and picture paths, and update the sheet numbers.
